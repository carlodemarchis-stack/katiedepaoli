# katiedepaoli.com

Personal landing page for Katie De Paoli. English at `/`, Italian at `/it/`.

Edit `strings.json` (both languages) or `template.html`, then run `python3 build.py`, commit and push.
Never hand-edit the generated `index.html` files. GitHub Pages serves `main` from the root; `CNAME` holds the domain.
Umami website id is in `strings.json` (`umami_id`); `?noumami` in the URL opts a browser out.
